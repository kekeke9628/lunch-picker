# 오늘 점심 뭐 먹지 🍽️

직장인 점심 메뉴 선택장애를 줄이는 단일 HTML 웹앱.
조건을 넣으면 후보 5곳을 뽑아주고, 그래도 못 고르면 룰렛이나 1:1 대결로 하나를 정해준다.

**[→ 바로 써보기](https://kekeke9628.github.io/lunch-picker/)**

`index.html` 파일 하나가 전부다. 빌드도, 서버도, 의존성도 없다.
(글꼴 Pretendard는 CDN에서 받고 못 받으면 시스템 글꼴로 대체된다. 지도는 Leaflet + OpenStreetMap 타일을
지도를 처음 열 때만 불러온다. 둘 다 API 키가 필요 없다.)

## 기능

- **위치 선택** — 서울 25개 구 전체의 주요 역·상권 46곳과 판교, 총 47곳 프리셋(구별로 묶여 있다), 브라우저 위치 권한으로 지금 있는 자리, 또는 **지도에서 직접 찍은 자리**.
  식당마다 좌표가 있어서 기준점을 바꾸면 도보 시간이 전부 다시 계산된다.
  지도에서는 도보 반경과 그 안의 식당 수가 바로 보이고, 지금 위치·지도 위치는
  주소(OpenStreetMap Nominatim 역지오코딩)로 표시된다. 등록된 권역에서 멀면 가장 가까운 권역을 알려준다.
- **조건 입력** — 도보 시간, 예산(최대치는 '상관없음'), 인원,
  오늘 기분(국물·가볍게·든든·매콤·빠름·분위기), 비 오는 날
- **후보 5곳** — 조건에 맞는 곳 중 점수 상위 5곳. 같은 종류는 최대 2곳까지만
- **결정 장치** — 룰렛(랜덤), 1:1 대결(서바이벌 토너먼트), 다시 굴리기
- **중복 회피** — 먹은 기록이 쌓일수록 최근에 간 곳과 최근에 먹은 종류를 피해서 추천한다
- **내 취향 반영** — 가격 수정, 별점, 특정 가게·종류 제외, 식당 직접 추가
- **기록과 통계** — 이번 달 뭘 몇 번 먹었는지
- **바로 결정** — 후보 카드마다 `여기로` 버튼. 룰렛·대결 없이 바로 고를 수 있고, 결과는 단톡방에 공유할 수 있다
- **오늘의 점심 카드** — 결정하면 추천받기 탭 맨 위에 남는다. 카카오맵 길찾기, 공유, 다녀와서 별점,
  먹은 메뉴 메모, 결정 취소. 이번 달 몇 번째 점심인지도 보여준다
- **메뉴·리뷰 보기** — 식당 데이터에 메뉴·리뷰가 없어서, 후보 카드·결정 화면에서 네이버 검색으로 연결한다.
  맨 위 가게 카드에서 메뉴와 방문자 리뷰 수·키워드 리뷰를 같이 볼 수 있다.
  직접 적은 메뉴 메모는 다음 추천 카드에 같이 보인다
- **🔥 리뷰 많음** — 네이버 지역검색 '리뷰 많은순' 상위에 오른 곳. 추천 점수에 조금 더 얹어준다(아래 참고)
- **쓰기 편하게** — 뽑기 버튼은 화면 아래 고정, 조건을 바꾸면 결과가 낡았다고 알려줌,
  기록 삭제·결정은 토스트에서 되돌리기, 식당 목록 검색, 라이트/다크/자동 테마,
  키보드(탭 화살표 이동, Esc로 닫기)와 `prefers-reduced-motion` 지원

## 쓰는 법

- **로컬**: `index.html`을 더블클릭
- **배포**: 이 저장소를 GitHub Pages / Vercel / Netlify 어디든 정적 호스팅
  (`📍 현재 위치 쓰기`는 HTTPS 또는 localhost에서만 동작한다)

설정·평점·먹은 기록은 브라우저 `localStorage`에만 저장된다. 서버로 나가는 데이터는 없다.
기기를 바꾸기 전에 **식당 관리 → 데이터 백업**에서 JSON을 내려받아 두면 된다.

## 추천 알고리즘

1. **하드 필터** — 도보 시간 초과, 예산 초과, 제외한 종류, 숨긴 가게를 걷어낸다.
2. **가중 점수**
   | 항목 | 점수 |
   |---|---|
   | 기분 태그 일치 | `+30` (태그당) |
   | 인원 조건 맞음 | `+12` |
   | 비 오는 날 국물 메뉴 | `+15` |
   | 내 평점 | `(평점 − 3) × 7` |
   | 🔥 리뷰 많음 | `+10` |
   | 랜덤 노이즈 | `±10` |
   | 어제 먹음 | `−60` |
   | 3일 내 먹음 | `−40` |
   | 7일 내 먹음 | `−25` |
   | 같은 종류를 3일 내 먹음 | `−20` |

   감점 항목이 가장 큰 역할을 한다. 매일 비슷한 게 나오면 앱을 안 쓰게 되기 때문이다.
   랜덤 노이즈는 같은 조건에서도 결과가 조금씩 달라지게 만든다.
   리뷰 많음 가산점은 기분 태그(+30)보다 훨씬 작게 잡았다. 유명한 곳만 계속 나오지 않게,
   비슷한 후보끼리 겨룰 때 한 번 더 밀어주는 정도다.
3. **다양성** — 상위 5곳을 뽑되 같은 종류는 최대 2곳까지.
4. **결정** — 룰렛(랜덤) 또는 1:1 대결(이긴 곳이 다음 상대를 만나는 서바이벌, 5곳이면 4판).
   결정하면 기록에 남고, 그 기록이 다음 추천의 감점 근거가 된다.

## 식당 데이터

`index.html` 안에 `const SEED = [...]` 로 1,837곳이 박혀 있다(서울 25개 구 전체 + 판교).
네이버 지역검색 API는 브라우저에서 직접 부를 수 없어서(CORS 차단 + Client Secret 노출),
수집을 빌드 타임으로 옮긴 구조다.

| 파일 | 내용 |
|---|---|
| `seed-raw.tsv` | 네이버 지역검색 원본 1,625행 (상호 / 업종 / 도로명주소 / mapx / mapy) |
| `popular-raw.tsv` | 같은 API를 `sort=comment`(리뷰 많은순)로 부른 결과 321행(겹치는 곳 빼면 319곳), 형식은 위와 같음 |
| `normalize-seed.py` | 중복 제거(상호+주소, 상호+좌표), 카테고리 10종 매핑, `mapx·mapy ÷ 10^7 → 위경도`, 술집·카페 제외, 리뷰 많음 표시 |
| `price-model.py` | 1인 점심값 추정 |

### 어떻게 모았나

네이버 지역검색은 한 번에 5곳까지만 준다. 그래서 역·상권마다 메뉴 종류별로 따로 검색했다.

- **처음 8곳**(강남·역삼·판교·여의도·광화문·을지로·구로디지털·상암): 358곳
- **서울 전역 확장**: 25개 구마다 1~5곳씩, 역·상권 39곳을 더 골랐다.
  각 상권마다 `백반 / 국밥 / 중식 / 일식 / 파스타 / 분식 / 쌀국수` 7종을 검색하고,
  술집·카페·병원처럼 점심과 무관한 결과는 뺐다. 1,267행이 늘었고 중복을 걸러 1,595곳이 됐다.

- **리뷰 많은순**: 47개 상권마다 `○○역 점심`(일부는 `밥집`도)을 공식 정렬 옵션 `sort=comment`로 검색해
  상위 5곳을 모았다. 기존 데이터에 있던 77곳에는 `"pop":1`을 달고, 없던 242곳은 새로 넣었다
  (뷔페·오마카세·술집·카페는 뺐다).
  네이버 API는 **별점이나 리뷰 수 자체는 주지 않는다.** 그래서 앱에는 숫자 없이 "리뷰 많음"만 표시하고,
  실제 리뷰는 `메뉴·리뷰` 버튼으로 네이버에서 본다. 목록은 수집 시점 기준이다.

상권 중심에서 도보 15분 안에 대략 20~120곳이 들어온다. 상권에서 멀리 떨어진 주택가는
아직 비어 있을 수 있고, 그런 위치를 고르면 앱이 가장 가까운 상권을 알려준다.

```sh
python3 normalize-seed.py            # -> restaurants.json
# 만들어진 JSON을 index.html 의 `const SEED = [...]` 자리에 넣으면 갱신된다
```

### 가격은 어떻게 매겼나

네이버 지역검색은 **가격·영업시간·평점을 주지 않는다.** 그래서 추정하되, 근거를 두고 추정한다.

```
1인 점심값 = 업종 기준가 × (그 가게가 속한 업무권역의 평균 점심값 ÷ 서울 평균)
```

- **업종 기준가** — 네이버의 세부 업종(44종)별로 잡는다.
  한국소비자원 참가격 2026년 서울 외식비가 기준점이다
  (김치찌개백반 8,654 · 자장면 7,692 · 칼국수 10,038 · 비빔밥 11,615 · 김밥 3,869).
  같은 "일식"이라도 `우동,소바`와 `초밥,롤`과 `초밥뷔페`는 기준가가 다르다.
- **권역 보정** — 식신e식권 2026 상반기 업무권역별 점심값을 서울 평균(11,586원)으로 나눈 값.
  여의도 14,000 · 강남 13,000 · 판교 12,500 · 종로·구로 10,000.
  가게 좌표에서 가장 가까운 권역을 적용하므로, **내가 고른 위치를 바꿔도 가격은 변하지 않는다.**
  조사된 권역에서 3km 넘게 떨어진 가게(노원·은평·강동 등)는 권역 보정 없이 서울 평균 기준가를 쓴다.
- **상호 예외** — 업종만으로 안 잡히는 가격대(`오마카세`, `구내식당`)는 상호를 보고 따로 처리한다.

결과적으로 분식은 6,000~9,500원, 일식은 8,500~38,000원으로 갈린다.
같은 분식이라도 강남 평균 8,750원, 구로 평균 6,950원이다.

**어디까지나 추정이고, 가게마다 실제로 확인한 값이 아니다.**
다르면 앱의 **식당 관리** 탭에서 고치면 되고, 고친 값이 이후 추천에 바로 반영된다.
고친 값은 상호+주소 해시를 키로 저장하므로 목록을 다시 수집해도 유지된다.

새로 생긴 가게는 앱에서 **직접 추가**하거나, 목록을 다시 수집해 위 과정을 반복하면 된다.
